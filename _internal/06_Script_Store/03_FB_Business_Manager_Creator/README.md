## ⚡ Overview
The **FB 1-Click Business Manager Creator** is a high-speed automation script that allows users to create multiple Facebook Business Managers (BMs) directly inside live browser sessions in **under 2 seconds per BM**.

It utilizes Facebook's internal Business creation API (`https://business.facebook.com/business/create_account`) to generate BMs, extract official `business_id` credentials, and display clickable direct links with instant clipboard export.

---

## 🌟 Key Features
- **Smart CDP Live Browser Attachment**: Connects seamlessly to active Chrome profiles without restarting or crashing.
- **Auto-Navigation**: Automatically navigates the active browser to `business.facebook.com` if not already loaded.
- **Live Streamed Links**: Each created BM appears with its name and clickable link directly to `https://business.facebook.com/latest/settings/ad_accounts?business_id=...`.
- **Smart Limit Detection**: Detects `Limit Reached For The Number Of Businesses` and finishes gracefully without hanging.
- **1-Click Copy All**: Instantly copies all created BM names and links to clipboard.
