স্বাগতম! এটি srkBrowser-এর একটি সম্পূর্ণ পোর্টেবল (Portable) ও স্বয়ংসম্পূর্ণ Customer Edition।

[সহজ ব্যবহার নির্দেশিকা / How to Run]:
1. কোনো Python, Node.js বা অতিরিক্ত সফটওয়্যার ইনস্টল করতে হবে না।
2. সরাসরি "Start_srkBrowser.exe" বা "srkBrowser.exe" ফাইলে ডাবল ক্লিক (Double Click) করুন।
3. সফটওয়্যার স্বয়ংক্রিয়ভাবে চালু হয়ে যাবে।

[ফিচারসমূহ / Features]:
• 100% Local & Offline-First Data Storage: আপনার সমস্ত প্রোফাইল ও ডেটা এই ফোল্ডারের 
  ভিতরে থাকা "data" ফোল্ডারে সুরক্ষিত থাকবে।
• 3টি পূর্ণাঙ্গ অটোমেশন বট (Automation Bots):
  1. ⚡ Facebook Bulk Video / Reel Uploader Bot (With Cloud Video Vault)
  2. ⚡ Facebook Bulk Page Creator Studio
  3. ⚡ Facebook Bulk ID Login Studio
• 6টি স্ক্রিপ্ট স্টোর মডিউল (Script Store Modules):
  1. FB 1-Click Quick Page Creator
  2. FB Language Converter
  3. FB Business Manager Creator
  4. FB Bulk Video Uploader
  5. FB 1-Click Auto Re-login
  6. FB 1-Click Account Info
• Built-in Isolated Portable Chromium Engine: ব্রাউজার রান করার জন্য আলাদা কোনো 
  ক্রোমিয়াম ডাউনলোড করতে হবে না।

[সতর্কতা / Note]:
- পুরো "srkBrowser_Customer_Edition" ফোল্ডারটি পেনড্রাইভ বা যেকোনো ড্রাইভে কপি করে নিয়ে 
  সরাসরি ব্যবহার করা যাবে।
- ডেটা ব্যাকআপ রাখতে চাইলে শুধুমাত্র "data" ফোল্ডারটি কপি করে রাখলেই চলবে।
